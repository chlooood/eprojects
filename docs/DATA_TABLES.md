# Data tables

All workflows share these n8n Data tables. W1 and W2 already have theirs. The rest must exist in the same n8n instance before the other workflows can run.
Create a missing one with Data tables > Create > Import CSV and the file in `data/tables/`, then delete the sample row. Copy each table ID from the URL into `workflows/wiring.json`, run `node scripts/wire-workflows.js`, then import.

BC comparison: the Coquihalla seed reuses these existing IDs. Its globally distinct `bc_coq_` IDs and `bc-coquihalla` corridor key isolate it from Edmonton. Source metadata uses `corridor_sources.source_kind=corridor_manifest`, with JSON in `fallback_reason`; the API selects it by corridor and kind. Forecast columns in the climate cache are Strings. The seed contains only upserts, never deletes or archive operations.
